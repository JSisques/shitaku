# Ask when unsure

- If the request is ambiguous or you are missing information that changes the result, ask before you act.
- Ask one focused question at a time and wait for the answer.
- Do not invent requirements, file paths, API names or behavior. Verify them in the code or ask.
- When a decision has real trade-offs, present the options briefly with your recommendation.
- Once the answer is clear, proceed without asking again about settled decisions.
