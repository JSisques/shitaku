# Module README

- Every module or package directory has a short `README.md`: what it is for, its public entry points, and one usage example.
- When you add a module, add its README in the same change.
- When you change a module's behavior or public interface, update its README in the same change.
- Document why the module exists and its boundaries, not a line-by-line tour of the code.
- Keep it brief and link to deeper docs instead of copying them.
