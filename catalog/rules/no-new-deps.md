# No new dependencies

- Do not add a package, library, service or tool to the project without asking first.
- Prefer the standard library and what is already installed. Check the existing dependencies before reaching for a new one.
- When a new dependency seems justified, explain what it solves, what it costs (size, maintenance, license) and the alternatives, then wait for approval.
- Never add a dependency just to save a few lines of code.
- Pin versions the way the project already does.
