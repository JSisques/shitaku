# Primeros pasos

Requiere Node `>=22.13`.

```sh
npx @jsisques/shitaku init
```

Ese único comando abre un plan interactivo: elige servidores MCP y skills del catálogo, revisa los cambios y aplícalos en ámbito de proyecto o de usuario.
