# Códigos de salida

| Código | Significado                                                            |
| ------ | ---------------------------------------------------------------------- |
| `0`    | Correcto                                                               |
| `1`    | Error                                                                  |
| `2`    | Conflictos sin resolver                                                |
| `3`    | `undo` o `uninstall` rechazado porque algo cambió desde la instalación |
| `4`    | `doctor` encontró problemas                                            |
